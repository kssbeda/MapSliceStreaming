# MapSliceStreaming — Source Code Overview

## 1. 개요

MapSliceStreaming은 Unity 6.3 LTS와 URP를 기반으로 개발한 모바일 오픈 월드 기술 데모입니다.

이 저장소에서는 Terrain 스트리밍, 자연환경 LOD, 원거리 숲 렌더링, 캐릭터 가림 및 지도 시스템의 핵심 구현 코드를 공개합니다.

공개 범위는 기술적 설계와 문제 해결 과정을 이해할 수 있는 주요 코드에 집중하며, 전체 Unity 프로젝트나 외부 에셋은 포함하지 않습니다.

## 2. World Streaming

플레이어 위치를 기반으로 필요한 Terrain 청크를 동적으로 선택하고 로딩·언로딩합니다.

### 주요 구현

- 플레이어 중심의 청크 관리
- 비동기 에셋 로딩과 상태 추적
- 중복 로딩 요청 방지
- Addressables 리소스 생명주기 관리
- 이동에 따른 청크 교체 및 해제

### 설계 핵심

청크의 필요 상태와 실제 로딩 완료 상태를 분리하고, 비동기 작업 중 플레이어가 이동하는 상황을 고려하는 것이 중요합니다.

## 3. Vegetation LOD

실제 나무 에셋을 기반으로 다섯 단계의 LOD를 구성하고 화면 상대 크기에 따른 전환 기준을 관리합니다.

### 주요 구현

- 나무 메시의 다단계 LOD 구성
- 근거리 고품질 메시 보존
- 원거리 메시 복잡도 관리
- LOD 전환 기준 설정
- Unity Editor 기반 반복 작업 자동화

### 설계 핵심

LOD 최적화는 삼각형 수를 줄이는 것뿐 아니라 나무의 실루엣과 잎의 형태를 자연스럽게 유지하는 것이 중요합니다.

## 4. Distant Forest Rendering

아직 로드되지 않은 Terrain 청크의 원거리 숲을 표현합니다.

### 주요 구현

- 실제 나무 배치 데이터 활용
- 수종별 저해상도 LOD 메시 재사용
- GPU Instancing 기반 반복 렌더링
- 청크 로딩 상태에 따른 표시 전환
- 원거리 숲과 실제 나무의 중복 표시 방지

### 설계 핵심

로드된 청크와 미로드 청크 사이의 시각적 연속성을 유지하는 것이 핵심입니다.

단순 프록시에서 실제 나무 기반의 경량 표현으로 변경하여 실루엣 차이를 줄이도록 설계했습니다.

## 5. Character Occlusion

환경 오브젝트가 캐릭터를 가리는 상황을 처리합니다.

### 주요 구현

- 캐릭터와 카메라의 상대 위치 활용
- 가림 대상 렌더러 관리
- 셰이더 파라미터 전달
- Alpha Clipping 및 Alpha Blending
- 식생 LOD 시스템과 독립적인 제어 구조

### 설계 핵심

환경 오브젝트 전체를 단순하게 숨기는 대신 캐릭터의 시야 확보에 필요한 부분을 처리하는 것이 주요 목적입니다.

## 6. World Map & Navigation

전체 지도와 미니맵을 통해 플레이어 위치, 목적지 및 경로를 표시합니다.

### 주요 구현

- 월드 좌표와 지도 좌표 변환
- 플레이어 위치 및 방향 표시
- 목적지 선택과 변경
- NavMesh 기반 경로 계산
- 이동 가능 격자 기반 예상 경로
- 경로 변경 및 갱신 처리

### 주요 코드

- `MapSliceRoutePlanner.cs`
- `MapSliceWalkGrid.cs`
- `MapSliceWalkGridBakerWindow.cs`
- `MapSliceWorldMapUI.cs`
- `MapSliceWorldMapData.cs`

## 7. Editor Tools

반복 작업을 자동화하고 프로젝트 설정을 검사하기 위한 Unity Editor 도구입니다.

### 주요 구현

- 자연 에셋의 LOD 생성과 설정
- LOD 전환 품질 조정
- 원거리 숲 데이터 생성 및 검사
- 이동 가능 격자 베이크
- 누락된 에셋과 설정 참조 점검

에디터 도구는 런타임 시스템과 역할을 분리하여 관리합니다.
